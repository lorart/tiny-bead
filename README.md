# Tiny Bead Studio 🎨🪡

> A cozy, free-to-play pixel art gacha and Perler bead pattern generator built for the web.

![Tiny Bead Banner](https://tinybead.com/art/og-cover.png)

## What is this?
I love pixel art, blind boxes, and physical crafts, so I built an app that combines them all. Tiny Bead is a web-based playground where you can pull random pixel characters (gacha style) and use an assembler to mix-and-match parts to create your own unique avatars. 

The best part? **You can export any character you create as a real-life Perler bead / Hama bead blueprint!** It automatically generates a craftable grid pattern so you can make physical keychains or decorations out of your digital pulls.

👉 **Play it here (No login required): [tinybead.com](https://tinybead.com)**

## Features
- 🎰 **Blind Box Gacha**: Pull from over 50+ hand-crafted pixel characters.
- ✂️ **Character Assembler**: A lightweight editor to build your own pixel avatars using unlocked parts.
- 🖨️ **Perler Bead Blueprints**: Export any character as a color-coded grid pattern for physical crafting.
- 🏢 **Cyber Apartment**: Place your collected characters in customizable isometric rooms.

## Tech Stack
Built lovingly with vanilla HTML/JS/CSS, Vite, and a custom WebGL rendering pipeline to handle the dynamic part assembly and grid generation.
